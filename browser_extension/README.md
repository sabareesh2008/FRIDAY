# ZYRA / FRIDAY Browser Bridge Extension

This lightweight Chrome / Edge / Brave extension allows ZYRA to:
- List all open browser tabs with exact titles and URLs.
- Switch directly to any tab by voice or text.
- Close specific tabs without affecting others (e.g. *"Close YouTube but leave my college portal open"*).
- Search browser history with zero privacy exposure.

---

### Installation Instructions (Chrome / Edge / Brave)

1. Open **Google Chrome** (or **Microsoft Edge** / **Brave**).
2. In the address bar, navigate to:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
3. Toggle ON **Developer mode** (top-right corner).
4. Click the **Load unpacked** button (top-left).
5. Select this folder:
   `C:\Sabareesh\ZYRA\browser_extension`
6. The extension is now installed! It connects automatically to ZYRA at `http://127.0.0.1:5005`.

---

### Privacy & Security
- This extension runs **100% locally** on your machine.
- It **does NOT** collect, store, or transmit any passwords, cookies, or session tokens.
